# 🌱 Sprouta (スプラウタ)

**Sprouta** は、子ども向けの「ひらがな」「カタカナ」「アルファベット」を学べる知育アプリケーションです。
直感的な操作と音声認識機能を活用し、遊び感覚で学習を進めることができます。

## はじめに
- このプログラムはコーディングAIを使用して開発されています。
- インストーラーなどは現状用意していません。

## 🌟 主な機能

- **マルチ学習モード**: ひらがな、カタカナ、アルファベットの学習に対応。
- **多様な入力方法**:
  - **ボタン選択**: 画面上のボタンをタッチして回答。
  - **キーボード入力**: 文字を入力して回答。
  - **音声認識**: マイクに向かって発音して回答（日本語・英語対応）。
  - **リスニング**: 読み上げられた音を聞いて正しい文字を選択。
- **やる気を育む仕組み**:
  - **プロフィール機能**: 好きなアバターを選んで自分だけの学習記録を作れます。
  - **スターとシール帳**: 正解するたびにスターが貯まり、一定数たまると可愛い動物シールを獲得できます。
- **保護者向けメニュー**:
  - 学習データの統計（正答率、苦手な文字ランキング）を確認できます。
  - ユーザー名の変更や記録のリセットが可能です。
  - 使用するマイクの切り替え設定ができます。

## 📋 動作環境

- **OS**: macOS (音声再生および合成機能が macOS の標準コマンド `afplay`, `say` に最適化されています)
  - 他のOSへの対応はリクエストがあれば。
- **Python**: 3.10 以上推奨

## 🚀 セットアップ

### 1. 依存ライブラリのインストール

```bash
pip install -r requirements.txt
```

※ 音声認識機能（SpeechRecognition）を使用するため、システムに `PortAudio` がインストールされている必要があります。macOS の場合は `brew install portaudio` でインストール可能です。

### 2. アプリケーションの起動

```bash
python src/main.py
```

## 📂 プロジェクト構成

```
sprouta/
├── src/
│   ├── main.py              # アプリケーションのエントリポイント (Flet GUI)
│   ├── database/
│   │   └── db_manager.py    # SQLite データベースの初期化と管理
│   └── utils/
│       ├── learning_engine.py # 問題生成ロジック
│       └── voice_manager.py   # 音声認識の管理
├── assets/
│   ├── images/              # 画像リソース
│   └── sounds/              # 効果音 (seikai.mp3, hazure.mp3 等)
├── sprouta.db               # 学習データ保存用データベース (自動生成)
└── requirements.txt         # 依存ライブラリ一覧
```

## 🛠 使用技術

- **GUI**: [Flet](https://flet.dev/) (Flutter based Python framework)
- **音声認識**: SpeechRecognition, PyAudio
- **日本語処理**: pykakasi (ひらがな・カタカナ変換)
- **データベース**: SQLite3
